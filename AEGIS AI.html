1. High-Level Architecture Overview

Veritas-AI (internally referenced in code modules as Aegis-AI) is a high-performance deepfake and synthetic image detection application. It utilizes vision models, neural autoencoders, and statistical signal processing to analyze face crops and assess biometric authenticity.

The platform is composed of a Flask Web API server, a localized SQLite relational user tracking database, offline ingestion processors, and an inference engine utilizing a serialized XGBoost Decision Classifier.

2. The Three Pipeline Architectures

The codebase implements three distinct feature extraction and classification pipelines tailored for varying runtime conditions:

Pipeline A: Production-Grade XGBoost Fusion Engine (Active)

This pipeline drives the online Flask application API and the CLI inspection client. To keep API response times minimal and resource footprints light, this pipeline avoids running heavy deep model inference on every HTTP request. Instead, it runs face crops through localized mathematical operators to extract 9 scalar biometric metrics. These metrics are normalized by a fit StandardScaler and evaluated by an XGBClassifier.

Model Metadata
Model structures and parameters are stored inside dataset/fusion_engine_best.json and scaler mean parameters are held inside dataset/scaler.json. This enables seamless, database-free, rapid-load inference.

Pipeline B: Deep Multi-Modal Cross-Attention Network (R&D V2)

Located in core/v2_architecture.py. This represents the high-capacity, multi-domain vision network research branch. It splits images across four distinct channels:

  • Spatial Domain Branch: Feeds resized images into a Swin-T Vision Transformer backbone (Swin-T Tiny Patch4 Window7 224 via timm).
  • Frequency Domain Branch: Processes Fast Fourier Transforms (FFT) through a modified 1-channel ResNet-18.
  • Latent Fingerprint Branch: Uses a 3-layer CNN to process VAE reconstruction errors ($E = |I_{input} - I_{recon}|$).
  • Statistical Realism Branch: Maps a 8192-dimensional texture feature vector (LBP/entropy) using a two-layer MLP.

Features from all domains are projected to a uniform 512-dimensional subspace. The spatial features function as a Query ($Q$), while the frequency, latent, and statistical features serve as Keys ($K$) and Values ($V$) in an 8-head Multi-Head Cross-Attention module to learn dynamic inter-domain correlations.

Pipeline C: Heuristic Multi-Model Hybrid Pipeline (Legacy / Ensemble)

Implemented in core/pipeline.py. Uses a classical multi-model weighting logic to fuse scores from an External API Detector, a local custom EfficientNet-B3 model, a discrete FFT analyzer, an LBP texture analyzer, and a spatial landmark symmetry analyzer.

3. The 9 Production Forensic Metrics

The production XGBoost classifier utilizes a vector of nine independent scalar features extracted directly from aligned face crops:

Spatial Score
Computes the absolute average intensity of the normalized, cropped facial tensor. Exposes general exposure, scaling, or boundary masking errors.
Frequency Score
Performs a 2D Fourier Transform (FFT) on grayscale pixels and computes the high-frequency energy in the outer 25% boundary margins. Detects artificial upsampling grids.
Latent Score
Measures the reconstruction error from the Stable Diffusion VAE (TAESD). Synthetic textures reconstruct with significantly lower errors than real high-frequency human skin.
Statistical Score
Measures Local Binary Pattern (LBP) entropy distributions across the face. Uncovers unnatural smoothness, absence of pores, or skin noise anomalies.
Shannon Entropy
Gauges pixel information content complexity. Flat, synthetic generative patterns exhibit lower entropy compared to natural variations.
Edge Density
Calculates the ratio of edge pixels using Canny edge filtering. Highlights splicing seams, structural double-exposures, and sharp boundary lines.
Laplacian Variance
Computes the variance of the image Laplacian. Exposes localized blur, out-of-focus editing blending, and facial sharpening corrections.
Color Kurtosis
Extracts statistical kurtosis scores per color channel (R, G, B) to evaluate color channel distributions. Detects artificial color balancing and pigment shifts.
JPEG Consistency
Applies discrete cosine transform (DCT) mapping and analyzes high-frequency coefficient variance. Exposes double compression artifacts typical of face-swapped images.

6. Hugging Face Spaces Deployment Configuration

The platform is designed to be fully containerized and hosted natively in a Hugging Face Space using the Docker SDK.

The live deployment is accessible publicly at: https://aditya150-veritas-ai.hf.space/

Hugging Face Spaces Sandbox Integration

  • Cross-Origin Iframe Safe-Cookies: Since Hugging Face renders Spaces in cross-origin frames, app.py sets cookie policies to SameSite=None and Secure=True. This ensures session tokens persist and prevents sudden logouts.
  • SSL Reverse Proxy Mapping: Leverages the Werkzeug ProxyFix middleware in Flask to process forwarded proxy headers, allowing secure cookies to function over Hugging Face's HTTPS layout.
  • Write Permissions Workaround (Variable UID): Hugging Face spaces execute containers as a randomized non-root user UID. The build pre-creates the directories static/uploads and instance and sets their permissions to 777 to permit SQL database locking and image saving without authorization exceptions.

Build Configuration (`Dockerfile`)

The Docker configuration builds an optimized environment that runs CPU-only inference to remain within standard free-tier Space hardware bounds: 

# Build a slim Python environment optimized for heavy machine learning
FROM python:3.11-slim

# Install system-level dependencies for computer vision (OpenCV/Pillow)
RUN apt-get update && apt-get install -y \
    libgl1 \
    libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

# Set working directory
WORKDIR /app

# Required directories for Flask + uploads
RUN mkdir -p static/uploads instance \

# Copy project files

# Upgrade pip
